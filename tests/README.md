# Tests

Black-box tests designed from the Requirements Traceability Matrix (RTM) verification column.

| File | Owner | Requirements |
| --- | --- | --- |
| `T1-Accessability/test_accessability_team1.py` | Team 1 | R01, R02, R03 |
| `test_workload_team4.py` | Cha | R11, R12, R23, R26 |

Naming: `test_<area>_<name>.py`, one file per person per area.
Run: `pytest -v` from the repository root.
